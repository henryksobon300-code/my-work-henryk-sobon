Experimental research

MathemaSpace and reproducibility

MathemaSpace is ongoing experimental work with alternative representations, typed relations, state transitions, observation planning and structural constraints. Its branches are separate methods and prototypes, not one universal engine with established performance across all domains.

The CORE-013 reproducibility repository describes one concrete bounded experiment with a frozen engine, provenance, independent checks and explicit claim limits. It does not represent independent institutional certification.

How I document results

I aim to state the exact problem and source data, freeze code and inputs, include a replay path and negative controls, and report failed approaches as well as successful ones. Independent confirmation of a concrete result is distinct from evidence that the underlying method is scientifically new.
