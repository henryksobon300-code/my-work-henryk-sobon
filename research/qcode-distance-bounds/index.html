Two tighter distance bounds for Campaign 7 codes

Explicit logical Pauli operators tighten the distance upper bounds for two non-CSS perturbed bivariate bicycle (PBB) codes in Qiskit’s qcode-discovery catalogue.

Catalogue record[[n,k]]Catalogue upper boundVerified upper bound
f0fdaa4514a87ad2[[360,10]]2216
331facaa1752ec16[[180,6]]2014

These are upper bounds. The exact minimum distances remain open in this report. Upstream review is pending.

Reproduce the check

Download the Python verifier and both certificates. The script uses only the Python 3 standard library.

python3 VERIFY_TWO_TRUSTED_BOUNDS_PUBLIC_20261027.py

Expected output is PASS for both records, with upper bounds 16 and 14. The verifier reconstructs the stabilizers from the public polynomials and checks their ranks, the witness weights and the two anticommuting pairs. For each record it rejects a damaged witness, an incorrect weight and a stabilizer substituted for the logical operator.

The linked source records are pinned to commit da9178f. Both sets of polynomial parameters and catalogue bounds matched the upstream main data checked on 12 November 2026.

Certificates

Each witness commutes with every stabilizer and anticommutes with a partner that also commutes with every stabilizer. A stabilizer would commute with the partner. Thus the witness is a nontrivial logical operator, and its weight bounds the distance from above.

The two blocks use zero-based indices block × (ℓ × m) + x × m + y.
