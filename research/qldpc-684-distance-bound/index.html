Weight-72 logical for a 684-qubit CSS code

A weight-72 Z logical on the existing 684-6-77 entry gives dZ ≤ 72 and d ≤ 72. The exact distance remains open.

QuantityCatalogue upper boundUpper bound with this witness
X distance7777
Z distance8072
Code distance7772

Why the witness proves the bound

  1. The Z operator acts on 72 distinct qubits and commutes with every X check.
  2. Its X partner commutes with every Z check. The two operators overlap on an odd number of qubits, so they anticommute.
  3. Every Z stabilizer commutes with that partner. The witness is therefore a nontrivial Z logical. Adding it to the Z checks also raises their binary rank from 339 to 340.

Reproduce the check

Download the Python verifier with both supports. It uses only the standard library and retrieves the pinned public matrix.

python3 verify.py

To run offline, give the verifier a local copy of the pinned matrix JSON.

python3 verify.py --source 684-6-77.json

The verifier checks the source SHA-256 before reading the matrix.
