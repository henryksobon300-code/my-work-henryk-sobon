Lower leading decoding error at fixed [[980,398,6]] parameters

A distinct CSS lifted-product code has a 3.869% smaller leading logical failure coefficient than the qLDPC Challenge code in PR #3867. The calculation assumes independent depolarizing noise, perfect syndrome measurements and maximum-likelihood recovery. The coefficient describes the limit as the physical error probability p approaches zero.

Proof and results

Each ambiguous weight-three syndrome has multiple equally likely logical alternatives. A class of size r contributes r − 1 unavoidable failures. A classification of all nonzero kernel supports through weight six makes this an exact count. It also proves distance six for both codes. The unequal Pauli counts establish inequivalence under qubit permutations and single-qubit Clifford operations.
