Two equivalent pairs of CSS catalogue entries

In each pair, one qubit permutation maps both the X and Z stabilizer row spaces onto those of the second entry. Each list uses zero-based indices, with source qubit i mapped to position p[i] in the target.

Row-space checks

The qLDPC Challenge verifier reports the ranks of the permuted source, the target and their stacked matrix. All three ranks agree in each sector. Enumerating every vector in each row space gives the same verdict. Swapping the first two images of either permutation breaks the equality in both sectors.

Challenge permutation verifier · Pinned catalogue revision

Reproduce the checks

Download the Python verifier. The script uses Python 3.10 or newer and its standard library. It retrieves the four pinned catalogue files and checks their SHA-256 values before testing the permutations.

python3 verify.py

For offline replay, save the four linked JSON files in one folder and pass that folder with --source-dir.

Catalogue scope

The equivalence is between the stabilizer groups. The entries carry separate layouts, circuits or distance certificates. Catalogue changes are subject to maintainer review.
